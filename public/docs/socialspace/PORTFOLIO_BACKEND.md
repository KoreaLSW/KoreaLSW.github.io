# 🔧 SocialSpace Backend

## 🎯 프로젝트 개요

Express.js와 TypeScript로 구축된 확장 가능한 RESTful API 서버입니다. PostgreSQL 데이터베이스를 활용하여 소셜 네트워크 플랫폼의 핵심 백엔드 로직을 처리하며, Socket.IO를 통한 실시간 통신을 지원합니다.

**프로젝트 유형**: Express.js를 활용한 Backend 개발  
**기술스택**: Node.js / Express.js / TypeScript / PostgreSQL / Socket.IO / Cloudinary

---

## 💡 프로젝트 목적

1. **확장 가능한 RESTful API 설계**

   - 70개 이상의 체계적인 엔드포인트 구축
   - 일관된 API 응답 포맷 및 에러 처리
   - 모듈화된 라우터 및 컨트롤러 구조

2. **실시간 통신 인프라 구축**

   - Socket.IO 기반 이벤트 드리븐 아키텍처
   - 실시간 채팅 및 알림 시스템

3. **보안 및 인증 체계 확립**
   - JWT 토큰 기반 인증
   - NextAuth와의 하이브리드 인증 시스템
   - CORS, XSS, SQL Injection 방어

---

## 기능구현 및 문제해결

### 1. JWT 기반 하이브리드 인증 시스템

NextAuth.js와 Express 서버 간의 인증 통합을 통해 프론트엔드와 백엔드 간 인증 상태를 일관되게 유지했습니다.

- **NextAuth JWT 토큰 검증**: `authenticateNextAuthToken` 미들웨어를 통해 Authorization 헤더에서 JWT 토큰을 추출하고 검증하여 사용자 정보를 `req.user`에 주입
- **선택적 인증 미들웨어**: `optionalAuth` 미들웨어를 구현하여 로그인 여부와 관계없이 접근 가능한 엔드포인트에서도 로그인 사용자에게 추가 정보 제공
- **70개 이상의 API 엔드포인트 보호**: 모든 엔드포인트에서 안전하게 사용자 인증을 처리하여 보안성 확보

### 2. 트랜잭션 기반 게시물 생성 시스템

게시물 생성 시 여러 쿼리로 나누어 저장하다 보면 중간에 오류가 발생할 경우 데이터 불일치가 발생하는 문제를 해결했습니다.

- **PostgreSQL 트랜잭션 활용**: BEGIN으로 트랜잭션을 시작하고, 게시물 생성, 이미지 저장, 해시태그 처리를 순차적으로 수행한 후 COMMIT으로 완료
- **자동 롤백**: 오류 발생 시 ROLLBACK을 통해 모든 변경사항을 취소하여 데이터 무결성 보장
- **데이터 일관성 유지**: 게시물 생성 과정에서 발생할 수 있는 부분 실패 상황을 방지하고 데이터 일관성을 유지

### 3. 차단 시스템 최적화 (Silent Block)

차단된 사용자의 게시물이나 댓글을 매번 개별적으로 필터링하면 쿼리 성능이 저하되는 문제를 해결했습니다.

- **미들웨어 기반 차단 관계 조회**: `silentBlock` 미들웨어를 구현하여 요청 초기 단계에서 차단 관계를 한 번만 조회하고 `req.blockedUsers`와 `req.blockerUsers`에 저장
- **N+1 쿼리 문제 방지**: 컨트롤러에서 저장된 정보를 활용하여 차단된 사용자의 콘텐츠를 필터링하거나 투명하게 차단
- **전역 일관성**: 차단 기능을 전역적으로 일관되게 적용하여 성능과 사용자 경험 개선

### 4. Socket.IO 실시간 통신 시스템

실시간 채팅과 알림 기능을 구현하기 위해 Socket.IO를 활용한 이벤트 기반 아키텍처를 구축했습니다.

- **사용자별 소켓 매핑**: Map 자료구조로 관리하여 온라인 상태를 추적하고, 룸 기반 브로드캐스팅을 통해 채팅방 멤버에게만 메시지 전송
- **실시간 메시지 동기화**: 메시지 전송 시 데이터베이스에 저장한 후 채팅방의 모든 멤버에게 실시간으로 브로드캐스트
- **개인별 알림 전송**: 사용자별 Socket 룸(`user:${userId}`)을 활용하여 알림을 개인별로 전송

### 5. Cloudinary 기반 이미지 업로드 최적화

이미지 파일을 서버에 직접 저장하면 서버 스토리지 부하가 증가하고 CDN을 통한 빠른 전송이 어려운 문제를 해결했습니다.

- **Multer 메모리 스토리지**: 5MB 크기 제한과 이미지 파일 타입 검증을 적용하여 안전한 파일 업로드 처리
- **자동 이미지 최적화**: Cloudinary에 업로드할 때 자동으로 1200x1200 크기로 리사이징하고 품질을 최적화하여 저장
- **Base64 이미지 지원**: 프론트엔드에서 압축된 Base64 형식의 이미지를 직접 업로드할 수 있도록 별도 엔드포인트 제공
- **CDN 활용**: 서버 스토리지 부하를 줄이고, CDN을 통한 빠른 이미지 전송 제공

### 6. 실시간 알림 시스템

팔로우, 좋아요, 댓글 등 다양한 이벤트에 대한 알림을 실시간으로 전송하는 시스템을 구현했습니다.

- **알림 설정 확인**: 사용자가 해당 알림 타입을 활성화한 경우에만 알림을 생성하여 맞춤형 알림 제공
- **Socket.IO 실시간 전송**: 데이터베이스에 알림을 저장한 후 Socket.IO를 통해 해당 사용자의 Socket 룸으로 즉시 전송
- **차단 관계 필터링**: 차단된 사용자의 알림은 생성하지 않도록 필터링하여 사용자 경험 개선

### 7. 비공개 계정 팔로우 시스템

공개 계정과 비공개 계정을 구분하여 팔로우 요청을 처리하는 시스템을 구현했습니다.

- **가시성 기반 팔로우 처리**: 사용자의 `visibility` 설정을 확인하여 비공개 계정인 경우 `pending`, 공개 계정인 경우 `accepted`로 설정
- **알림 최적화**: 팔로우가 승인된 경우에만 알림을 생성하여 불필요한 알림 방지
- **관계 관리**: 언팔로우 시 데이터베이스에서 관계를 삭제하고 관련 알림을 정리하여 데이터 일관성 유지

### 8. 데이터베이스 쿼리 성능 최적화

게시물 목록을 조회할 때 각 게시물의 작성자 정보를 개별적으로 조회하는 N+1 쿼리 문제를 해결했습니다.

- **JOIN을 활용한 쿼리 최적화**: 한 번의 쿼리로 게시물과 작성자 정보를 함께 조회하여 N+1 쿼리 문제 해결
- **복합 인덱스 생성**: 자주 사용되는 쿼리 조건에 대해 복합 인덱스를 생성하여 검색 성능 향상
- **페이지네이션 적용**: 한 번에 불러오는 데이터 양을 제한하여 서버 부하 감소
- **커넥션 풀 관리**: 데이터베이스 연결을 효율적으로 관리하여 성능 개선

### 9. 보안 강화 및 방어 체계

다양한 보안 위협으로부터 시스템을 보호하고 사용자 데이터의 안전성을 확보했습니다.

- **비밀번호 해싱**: bcryptjs를 활용하여 비밀번호를 해싱하여 저장하고, 솔트 라운드를 10으로 설정하여 무차별 대입 공격에 대비
- **CORS 설정**: 허용된 도메인에서만 API 요청을 받도록 제한하여 보안 강화
- **SQL Injection 방지**: 모든 쿼리에 Parameterized Query를 사용하여 SQL Injection 공격 방지
- **XSS 공격 방지**: HTML 태그를 이스케이프하는 유틸리티 함수를 구현하여 사용자 입력을 안전하게 처리

### 10. 통합 에러 처리 시스템

다양한 종류의 에러를 일관되게 처리하고 클라이언트에게 명확한 에러 메시지를 제공하는 시스템을 구현했습니다.

- **에러 타입별 처리**: ValidationError는 400, UnauthorizedError는 401, 기타 에러는 500으로 적절한 HTTP 상태 코드와 에러 메시지 반환
- **에러 로깅**: 모든 에러를 로깅하여 디버깅을 용이하게 하고, 프로덕션 환경에서는 민감한 정보를 노출하지 않도록 처리
- **일관된 에러 응답**: 일관된 에러 응답 형식을 제공하여 클라이언트에서 에러를 효율적으로 처리할 수 있도록 개선
