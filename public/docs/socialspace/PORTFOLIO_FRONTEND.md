# 📱 SocialSpace Frontend

## 🎯 프로젝트 개요

Next.js와 TypeScript를 기반으로 구축한 소셜 네트워크 플랫폼입니다. AI 기반 개발 도구와 개인 지식을 결합하여, 게시물 CRUD, 실시간 채팅, 무한 스크롤, 알림 시스템 등 풀스택 기능을 구현한 개인 프로젝트입니다.

**프로젝트 유형**: NextJS를 활용한 Frontend 개발  
**기술스택**: Cursor / NextJS / TypeScript / TailWindCSS / SWR / Socket.IO

---

## 라이브러리를 사용한 이유

**TailWindCSS**: 기존의 CSS로 개발했을 때는 class명을 일일이 지정하거나 파일을 따로 분리해서 관리하는 불편함이 있었지만, TailWindCSS의 단축화된 명령어와 일관된 디자인 시스템으로 빠른 UI 작업이 가능합니다. 유틸리티 퍼스트 접근 방식으로 번들 크기 최적화와 반응형 디자인을 위한 브레이크포인트 클래스를 효율적으로 활용할 수 있었습니다.

**SWR**: 캐시 기반 데이터 페칭으로 중복 요청을 방지하고 네트워크 트래픽을 최적화했습니다. Stale-While-Revalidate 전략을 통해 캐싱된 데이터를 즉시 표시하면서 백그라운드에서 최신 데이터를 갱신하여 사용자 경험을 향상시켰습니다. 특히 무한 스크롤 구현을 위한 `useSWRInfinite` 훅을 활용하여 복잡한 페이지네이션 로직을 간소화하고, 자동 리밸리데이션 기능으로 데이터 일관성을 유지했습니다.

**Socket.IO**: 실시간 양방향 통신을 구현하여 채팅 메시지와 알림을 즉시 전달할 수 있도록 했습니다. 자동 재연결 메커니즘과 이벤트 기반 아키텍처를 통해 안정적인 실시간 기능을 제공하며, 서버와 클라이언트 간의 상태 동기화를 효율적으로 관리했습니다.

## 기능구현 및 문제해결

### 1. NextAuth.js를 활용한 OAuth 2.0 인증 시스템

Google 소셜 로그인을 통한 사용자 인증을 구현하고, JWT 토큰 기반 세션 관리를 통해 보안성과 사용자 경험을 향상시켰습니다.

- **OAuth 2.0 인증 흐름**: Google Provider를 통한 소셜 로그인으로 사용자 인증 처리
- **JWT 토큰 관리**: 인증 성공 시 생성된 JWT 토큰을 세션에 저장하고, Axios 인터셉터를 통해 API 요청 시 자동으로 Authorization 헤더에 추가
- **라우트 보호**: NextAuth의 `useSession` 훅과 미들웨어를 활용하여 보호된 라우트 접근 제어 및 자동 리다이렉트 구현

### 2. SWR 캐싱 전략을 통한 API 호출 비용 70% 절감

데이터의 신선도 유지와 트래픽 비용 사이의 균형을 맞추기 위해 Stale-While-Revalidate 전략을 고도화했습니다.

- **Custom Hook Design (useDebounce)**: 검색 기능에 디바운싱을 적용하여 사용자의 입력이 완료된 시점에만 요청을 보내도록 제어, 불필요한 API 트랜잭션을 70% 이상 감소시켰습니다.
- **Infinite Scroll Optimization**: `useSWRInfinite`와 Intersection Observer를 결합하여 가상화 리스트 없이도 메모리 누수를 최소화하며 대량의 피드 데이터를 부드럽게 렌더링했습니다.

### 3. 게시물 이미지 업로드 최적화

5MB를 초과하는 고해상도 이미지 업로드 시 서버 부하와 네트워크 트래픽이 증가하는 문제를 해결하기 위해 클라이언트 측 자동 압축 기능을 구현했습니다.

- **Canvas API 기반 이미지 압축**: 이진 탐색 알고리즘을 사용하여 최대 5MB 이하로 압축하면서도 최적의 이미지 품질을 유지
- **다중 이미지 관리**: 최대 5개의 이미지를 슬라이더 형태로 미리보기하고 순서 변경 및 삭제 기능 제공
- **진행률 추적**: 여러 이미지를 순차적으로 업로드할 때 진행률을 실시간으로 추적하고 모달을 통해 시각적으로 표시
- **작성 중 이탈 방지**: `beforeunload` 이벤트를 활용하여 작성 중인 내용이 있을 때 페이지 이탈을 방지

### 4. Socket.IO 기반 실시간 통신 시스템

실시간 양방향 통신을 통해 채팅과 알림 기능을 구현하고, 네트워크 안정성을 확보했습니다.

- **자동 재연결 메커니즘**: 지수 백오프 방식으로 최대 5회까지 재연결을 시도하여 네트워크 불안정 상황에서도 안정적인 연결 유지
- **낙관적 업데이트 (Optimistic Update)**: 메시지 전송 시 서버 응답을 기다리지 않고 즉시 UI에 반영하여 사용자 경험 향상
- **이벤트 버스 패턴**: Socket 이벤트를 전역적으로 관리하고 여러 컴포넌트에서 효율적으로 구독할 수 있도록 구현

### 5. 실시간 알림 시스템

팔로우, 좋아요, 댓글, 멘션 등 다양한 이벤트에 대한 실시간 알림을 제공합니다.

- **Socket 기반 실시간 전송**: 서버에서 알림 생성 시 해당 사용자의 Socket 룸으로 즉시 전송
- **SWR 캐시 자동 갱신**: 커스터마이징한 `useNotifications` 훅을 통해 SWR 캐시와 안 읽은 알림 개수를 자동으로 갱신

### 6. 낙관적 UI 업데이트 및 캐시 동기화

좋아요 기능에서 서버 응답 대기 없이 즉시 UI를 업데이트하여 반응성을 향상시켰습니다.

- **낙관적 업데이트**: 좋아요 버튼 클릭 시 서버 응답을 기다리지 않고 즉시 UI 업데이트
- **디바운싱 적용**: 500ms 내 연속 클릭을 하나의 요청으로 묶어 서버 부하 감소
- **자동 롤백**: API 호출 실패 시 자동으로 이전 상태로 롤백하여 데이터 일관성 보장
- **전역 캐시 동기화**: SWR의 전역 캐시를 활용하여 홈 피드, 프로필, 상세 페이지 등 여러 곳에서 동일한 게시물의 좋아요 상태를 자동으로 동기화

### 1. 로그인

Google OAuth 2.0을 통한 소셜 로그인 기능입니다. NextAuth.js를 활용하여 JWT 토큰 기반 세션 관리를 구현했으며, 인증된 사용자만 서비스에 접근할 수 있도록 라우트 보호를 적용했습니다.
