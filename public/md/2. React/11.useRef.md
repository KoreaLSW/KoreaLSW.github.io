# 📌 React `useRef` 핵심 정리

## 1. 정의

> <b>"값이 바뀌어도 리렌더링을 발생시키지 않는 저장소"</b>이자 <b>"DOM 요소에 직접 접근하는 도구"</b>

- `useState`가 <b>"방송국"</b>이라면 (바뀌면 화면을 다시 그려서 온 동네에 알림),
- `useRef`는 <b>"서랍 속의 포스트잇"</b>입니다 (바뀌어도 조용히 값만 바뀜).

---

## 2. 사용하는 이유

`useRef`를 쓰는 이유는 크게 <b>2가지</b>입니다.

### ① 변수 관리 (저장소 용도)

- <b>목표:</b> 컴포넌트가 리렌더링 되어도 <b>값은 유지</b>하고 싶지만, <b>화면을 다시 그릴 필요는 없을 때</b> 사용합니다.
- <b>예시:</b>
  - `setTimeout` / `setInterval`의 ID 저장
  - 스크롤 위치 저장
  - 이전 상태값(Previous Value) 기억하기

### ② DOM 직접 접근 (선택자 용도)

- <b>목표:</b> 자바스크립트의 `document.getElementById`처럼 특정 태그를 직접 선택해야 할 때 사용합니다.
- <b>예시:</b>
  - `input` 요소에 포커스 주기 (`.focus()`)
  - 비디오/오디오 재생 및 정지
  - 스크롤 박스 조작

---

## 3. 사용법

`useRef`가 반환하는 객체는 `{ current: 초기값 }` 형태입니다.
<b>모든 값은 `.current` 프로퍼티 안에 들어있습니다.</b>

```javascript
const myRef = useRef(0);

console.log(myRef.current); // 값 읽기
myRef.current = 100; // 값 수정 (리렌더링 안 됨!)
```

## 4. 코드예시

##### [예시 1] 변수 관리 (리렌더링 방지)

```javascript
function Counter() {
  const countRef = useRef(0); // 내부 변수

  const handleRefClick = () => {
    countRef.current = countRef.current + 1;
    console.log("Ref 값:", countRef.current);
    // 콘솔에는 1, 2, 3... 찍히지만 화면 숫자는 그대로임!
  };

  return <button onClick={handleRefClick}>Ref 증가 (조용함)</button>;
}
```

##### [예시 2] DOM 접근

```javascript
function TextInput() {
  const inputRef = useRef(null); // 초기값 null

  const onFocus = () => {
    // .current가 실제 <input> 태그를 가리킴
    inputRef.current.focus();
  };

  return (
    <>
      <input ref={inputRef} type="text" />
      <button onClick={onFocus}>입력창으로 이동!</button>
    </>
  );
}
```

## 5. 핵심 비교: `useState` vs `useRef` vs `let`

가장 헷갈리는 3가지 변수 선언 방식의 차이점입니다.

| 구분            | useState                 | useRef                         | let (일반 변수)           |
| :-------------- | :----------------------- | :----------------------------- | :------------------------ |
| <b>주 용도</b>     | <b>화면</b>에 보여줄 데이터 | <b>화면과 무관한</b> 데이터 / DOM | 임시 계산용 변수          |
| <b>값 변경 시</b>  | <b>리렌더링 발생 (O)</b>    | <b>리렌더링 발생 안 함 (X)</b>    | 리렌더링 발생 안 함 (X)   |
| <b>리렌더링 후</b> | <b>값 유지됨</b>            | <b>값 유지됨</b>                  | <b>초기화됨 (0으로 리셋)</b> |

> <b>💡 요약</b>
>
> - 화면을 바꿔야 한다? 👉 `useState`
> - 화면은 안 바꿔도 되는데 값은 기억해야 한다? 👉 `useRef`
> - 그냥 잠깐 쓰고 버릴 거다? 👉 `let`
