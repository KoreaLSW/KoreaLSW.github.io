# 📌 `useMemo` 핵심 정리

## 1. 정의 (Definition)

> <b>"복잡한 계산 결과를 메모이제이션(Memoization)해두고, 필요할 때만 꺼내 쓰는 훅"</b>

- <b>`useMemo`</b>는 <b>값(Value)</b>을 캐싱합니다.
- 리렌더링이 발생하더라도, <b>의존성 배열(dependency array)</b>에 있는 값이 바뀌지 않았다면 이전에 계산해둔 결과를 그대로 반환합니다.

### 여기서 메모제이션(Memoization)이란?

메모제이션은 <b>이전에 계산한 결과를 메모리에 저장해두고, 같은 입력이 들어왔을 때 다시 계산하지 않고 저장된 결과를 재사용하는 최적화 기법</b>입니다.

---

## 2. 사용하는 이유

리액트 컴포넌트는 <b>상태(State)가 하나라도 바뀌면 컴포넌트 전체가 다시 실행(리렌더링)</b>됩니다.

### 🚨 문제 상황

1. 컴포넌트 안에 <b>엄청 오래 걸리는 계산(10초 소요)</b> 함수가 있음.
2. 사용자가 이 계산과 전혀 상관없는 `input` 창에 글자를 입력함 (State 변경).
3. 컴포넌트가 리렌더링되면서 <b>10초 걸리는 계산이 또 실행됨.</b>
4. 앱이 버벅거림.

### ✅ 해결책 (`useMemo`)

- <b>"이 계산은 관련된 값이 바뀔 때만 다시 해! 그 외에는 아까 계산한 거 그냥 써!"</b> 라고 리액트에게 시키는 것.
- <b>결과:</b> 불필요한 연산을 건너뛰어 <b>성능을 최적화</b>할 수 있습니다.

---

## 3. 사용법 및 문법

```javascript
// calculateValue: 무거운 계산 함수
// dependencies: 이 배열 안의 값이 바뀔 때만 계산을 다시 함
const cachedValue = useMemo(() => calculateValue(a, b), [a, b]);
```

## 4. 예시

```javascript
import React, { useState, useMemo } from "react";

// 1. 엄청 오래 걸리는 무거운 함수 (가정)
const hardCalculate = (number) => {
  console.log("🔥 무거운 계산 중... (시간 걸림)");
  for (let i = 0; i < 100000000; i++) {} // 시간 지연 시뮬레이션
  return number + 10000;
};

function App() {
  const [hardNumber, setHardNumber] = useState(1);
  const [isDark, setIsDark] = useState(false);

  // ❌ useMemo가 없을 때:
  // isDark(테마)만 바꿔도 App이 리렌더링되면서 이 함수가 또 실행됨.
  // const hardSum = hardCalculate(hardNumber);

  // ✅ useMemo를 썼을 때:
  // hardNumber가 바뀔 때만 계산함. isDark가 바뀔 땐 그냥 저장된 값(hardSum)을 재사용.
  const hardSum = useMemo(() => {
    return hardCalculate(hardNumber);
  }, [hardNumber]); // 의존성 배열: hardNumber

  return (
    <div>
      <h3>무거운 계산기: {hardSum}</h3>
      <input
        type="number"
        value={hardNumber}
        onChange={(e) => setHardNumber(parseInt(e.target.value))}
      />

      <hr />

      {/* 이 버튼을 누를 때 useMemo 덕분에 딜레이가 없음 */}
      <button onClick={() => setIsDark(!isDark)}>
        테마 변경 (배경색 바꾸기)
      </button>
    </div>
  );
}

export default App;
```
